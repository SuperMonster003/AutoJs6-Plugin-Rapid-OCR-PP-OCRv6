# Инструкции плагина

## Идентификация

- Действие: `org.autojs.plugin.PADDLE_OCR`
- Движок: `rapid-ocr`
- Вариант: `pp-ocrv6`
- ID плагина: `rapid-ocr-pp-ocrv6`

## Распознавание

- `recognizeText` возвращает список строк распознанного текста.
- `detect` возвращает обнаруженные блоки с текстом, уровнем достоверности и границами.

## Ввод

- Кодированные изображения декодируются из предоставленного файлового дескриптора.
- Необработанный ввод использует пиксели ARGB_8888 с метаданными ширины, высоты и шага строки.

## Параметры

- `maxSideLen` соответствует `OcrOptions.detLongSize` и задает максимальную длину стороны изображения для обнаружения. Значение по умолчанию равно 1024.
- `scoreThreshold` соответствует `OcrOptions.scoreThreshold` и задает минимальную допустимую оценку обнаружения. Значение по умолчанию равно 0.5.
