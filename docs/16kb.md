# 16 KB page alignment

Builds apply `io.github.supermonster003.autojs6-native-alignment:1.8.0`. Every assembled APK
is checked and reports are written to `app/build/reports/native-alignment/`.
Use `:app:verifyNativePageAlignment` to recheck existing artifacts.

The gate enforces ELF PT_LOAD alignment for arm64-v8a and x86_64. Uncompressed `.so` entries also require 16 KB ZIP alignment. Third-party 32-bit alignment is advisory.

Every native dependency or toolchain upgrade must pass the gate again. Static alignment
does not prove runtime behavior: test on a device reporting `getconf PAGE_SIZE = 16384`
with compatibility mode disabled. No `android:pageSizeCompat` override is permitted.

中文: 构建门禁检查全部产物并输出 JSON 报告. 原生依赖或工具链升级后必须重新校验,
且需在页大小为 16384 的设备上关闭兼容模式后执行运行时验证.

[Deployment and device acceptance matrix](https://github.com/SuperMonster003/AutoJs6/blob/master/docs/dev/page-size-16kb-roadmap.md)

Rapid OCR uses Maven ONNX Runtime 1.21.1 and the verified OpenCV 4.8.0 shared runtime.
The former OpenCV Mobile / static OpenMP combination aborts when Paddle Lite and Rapid
are loaded in the same user APK. The replacement uses TBB, shares the dedicated OpenCV
plugin runtime when selected, and keeps older Rapid APKs valid without the optional library.
The per-ABI library and header hashes are in `libs/opencv-native-4.8.0.provenance.json`;
the donor build recipe is `AutoJs6-Plugin-OpenCV/scripts/opencv/build-native-aar.ps1`.
Reproduce packaging with the host's `tools/16kb/refresh_rapid_opencv.py`.
This adds the OpenCV runtime to standalone Rapid APKs; it is deduplicated in user APKs.
The plugin requires AutoJs6 build 5279 or newer for this optional native dependency to
be copied correctly when generating a user APK.

ABI packaging: the app and plugin metadata include `arm64-v8a`, `armeabi-v7a`,
`x86`, and `x86_64`, with one APK per ABI and a four-ABI universal APK.
The SDK already builds `libRapidOcr.so` for all four ABIs, using matching slices
from ONNX Runtime 1.21.1 and the verified OpenCV AAR. Its existing NDK 28.2
`c++_shared` configuration supplies the C++ runtime for each ABI; no extra
prebuilt runtime is needed. After changing the ABI list, run `:app:assembleRelease`
and `:app:verifyNativePageAlignment`, then verify model loading and OCR on the
new target ABI.
